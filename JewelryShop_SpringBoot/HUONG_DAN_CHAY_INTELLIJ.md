# Hướng dẫn chạy LUMIÈRE Jewelry trên IntelliJ IDEA

1. Mở project `JewelryShop_SpringBoot`.
2. Chọn Project SDK là Java 17.
3. Mở `pom.xml` và chọn Reload Maven.
4. Chạy class `com.agile.jewelryshop.JewelryShopApplication`.
5. Mở `http://localhost:8080`.
6. H2 console: `http://localhost:8080/h2-console`.

Tài khoản demo:
- ADMIN: admin@lumiere.vn / admin123
- STAFF: staff@lumiere.vn / staff123
- CUSTOMER: user@lumiere.vn / user123

CSDL mặc định dùng H2 file tại `./data/jewelryshopdb`.
